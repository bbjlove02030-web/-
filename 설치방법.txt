월급날 자산관리 PWA - 설치 안내

포함 파일
- index.html: 앱 화면 및 기능
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시
- icon-192.png / icon-512.png: 앱 아이콘

중요한 재무 가정
- 월 실수령액: 3,000,000원
- 월세: 450,000원
- 신용회복위원회 대출: 15,000,000원, 연 4%, 60개월 원리금균등상환 가정
- 월 원리금 추정: 약 276,248원 (실제 약정서 납입액이 우선)
- 공과금 50,000원, 휴대폰 20,000원, 교통비 70,000원
- 동생 상환 50,000원, 구독 50,000원
- 식비 336,000원 (평일 저녁 월 20끼 + 주말 8끼, 9,000원/끼 가정)
- 용돈 300,000원 (담배 포함)
- 청년미래적금 500,000원, 주택청약 100,000원
- 비상금 저축 400,000원, ISA 250,000원, 추가 목돈 저축 100,000원
- 월말 예비비 47,752원
- 정기 상여금 예상: 2월 150만, 5월 80만, 9월 150만. 기본 월급 예산에는 미포함.
- 비상금 목표: 5,000,000원

안드로이드 홈 화면 설치 - GitHub Pages 방식
1. PC 또는 휴대폰 브라우저에서 github.com 접속 후 로그인/가입.
2. 우측 상단 + > New repository 선택.
3. Repository name에 payday-wealth-app 입력.
4. Public 선택, Add a README file 체크 후 Create repository.
5. Add file > Upload files 선택.
6. 압축을 푼 폴더 안의 파일 5개(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png)를 모두 업로드.
7. Commit changes 누르기.
8. 저장소 Settings > Pages로 이동.
9. Build and deployment에서 Deploy from a branch 선택.
10. Branch main, folder /(root) 선택 후 Save.
11. 1~3분 기다린 뒤 Pages 화면에 표시되는 https://계정이름.github.io/payday-wealth-app/ 주소 열기.
12. Android Chrome으로 주소를 열고 우측 상단 ⋮ > 앱 설치 또는 홈 화면에 추가 선택.
13. 홈 화면에 생성된 '자산관리' 아이콘을 눌러 실행.

Cloudflare Pages 대안
1. 압축을 푼 폴더에서 앱 파일 5개가 바로 보이게 준비.
2. Cloudflare 계정 로그인 > Workers & Pages > Create > Pages > Upload assets(Direct Upload) 선택.
3. 프로젝트 이름을 payday-wealth-app 등으로 입력.
4. 파일 5개를 업로드하고 Deploy.
5. 생성된 https://....pages.dev 주소를 Android Chrome에서 열고 ⋮ > 앱 설치/홈 화면에 추가.

설치 후 사용
- 월급날 체크: 기준 월을 선택하고 납부/이체/투자 완료 시 체크.
- 비상금: 비상금 잔액을 직접 입력하고 저장.
- 자산 기록: 매월 현금·예금, ISA 평가금액, 청년미래적금 잔액, 청약 잔액, 기타 저축, 대출 잔액을 입력하고 저장.
- 순자산 = 기록한 금융자산 합계 - 대출 잔액.
- 과거 월별 기록은 남고, 그래프에 순자산 흐름이 표시됨.
- 상여금: 실제 입금된 월과 금액만 기록.
- 백업: 정기적으로 JSON 백업 파일을 내려받아 보관. 다른 기기에서 복원 가능.
- CSV: 월별 자산 기록을 엑셀 등에서 열 수 있음.

주의
- 앱은 입력 데이터를 서버로 전송하지 않고 해당 브라우저의 로컬 저장공간에 저장합니다.
- 브라우저 데이터 삭제/앱 제거/기기 변경 전에 JSON 백업을 내려받으세요.
- 같은 앱 주소라도 브라우저별 저장공간은 별개입니다.
- 인터넷이 처음 필요하고, 설치 후 일부 화면은 오프라인에서도 열리도록 캐시합니다.
- iPhone은 Safari의 공유 > 홈 화면에 추가를 사용합니다.
- 대출 상환액 및 예산은 추정치입니다. 실제 금융기관 약정서와 실제 지출이 우선입니다.
